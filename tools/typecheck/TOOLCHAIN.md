# Offline verification toolchain (no Android SDK, no Google Maven)

Built 2026-10-26 in a sandbox where only GitHub (git + release downloads) is reachable. Everything below is
compiled from official sources; nothing is downloaded as a binary except the Kotlin compiler release.

## How the AndroidX stubs are made (`scripts/build_androidx.py`)

1. Sparse, blob-less worktree of `github.com/androidx/androidx` at the freeze commit of each library.
2. Kotlin sources of the Android source-set chain (`commonMain → jvmAndAndroidMain → [jvmMain] → androidMain`)
   are rewritten by **KStub** (`scripts/kstub/KStub.kt`, uses the Kotlin compiler's own PSI parser): function and
   accessor bodies → `TODO()`, default values → `TODO()` (lambdas keep their parameter list), `init` blocks removed,
   property initialisers → `TODO()` (backing fields kept where accessors use `field`), lint-only annotations
   removed. **Signatures, modifiers, annotations (`@Composable`, `@Deprecated(level=…)`, opt-in markers,
   `@DslMarker` scope markers …), expect/actual and private/internal declarations are kept verbatim.**
3. Compiled per library with kotlinc as a multiplatform module (`-Xfragments`), with the Compose plugin for
   Compose-based libraries, against the jars built before it.
4. Java classes of mixed/Java libraries (core, documentfile, versionedparcelable …) come from the library's
   restricted signature file via `sig2jar.py` (restricted = public + `@RestrictTo`, both callable in reality).
5. Declarations that cannot compile because a dependency is not available (kotlinx-serialization, Android 37
   or mainline-module APIs, androidx.startup …) are removed by an error-driven loop; every removal is logged in
   `build/ax/<lib>/drops.log`. `scripts/api_coverage.py` compares a stub jar against the official API file.

## Usage

```bash
# Android/Compose module (exit code 0 = no errors; all diagnostics are printed)
./typecheck.sh --module app \
  --res de.example.app=app/src/main/res \
  --buildconfig de.example.app --application-id de.example.app --version-code 1 --version-name 0.1.0 \
  --field 'APP_NAME=String:"Aether"' \
  --cp /tmp/out/designsystem.jar \
  -- app/src/main/java

# library module whose output other modules need
./typecheck.sh --module designsystem --res de.example.design=ui/designsystem/src/main/res \
  --out /tmp/out/designsystem.jar -- ui/designsystem/src/main/java

# pure Kotlin/JVM module: compile + run JUnit tests
./jvmtest.sh --module model --src core/model/src/main/kotlin --test core/model/src/test/kotlin
```

Options: `--opt-in FQNAME`, `--no-compose`, `--jvm` (JDK 17 API instead of Android), `--werror`.
`typecheck.sh` passes `-Xno-inline` (the stubs' inline bodies are `TODO()`); front-end checks are unaffected.

## Fidelity – what is and is not checked

Checked like a real build: resolution of every Android/AndroidX/Compose symbol, types, nullability (Android SDK
annotations treated as strict), `@Composable` context, Compose DslMarker scopes, `@Deprecated(level = ERROR/HIDDEN)`,
opt-in requirements (`@ExperimentalMaterial3Api` …), visibility, overrides, expect/actual of stubs,
R/BuildConfig references.

Not covered: resource linking (only R *names* are generated), manifest merging, KSP/Room/annotation processing,
Lint (`NewApi`, permissions …), R8, real Gradle dependency resolution, runtime behaviour. Known stub gaps:

* Android framework: APIs only in mainline modules not mirrored on GitHub (Connectivity `android.net.*` except
  `Uri`, Wi-Fi, Bluetooth, `android.icu`, `android.system.Os`/`ErrnoException`, `org.json`, `org.xmlpull` …) are
  empty placeholder classes (see `stubs/android-placeholders.txt`): they resolve, but have no members.
  `android.graphics.ColorMatrix` is missing from the mirrored API file (placeholder as well).
* Java SE 17 is a slight superset of Android's java.* (e.g. `java.util.HexFormat`).
* kotlinx-serialization based AndroidX APIs (savedstate/lifecycle `serialization` packages,
  `rememberSerializable`) are absent.
* `@FlaggedApi` framework APIs are all included, even flags that are off in the released SDK.
* Removed declarations per library: `build/ax/<lib>/drops.log`.
